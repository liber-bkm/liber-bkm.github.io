## First launch

On device the app uses private storage (config plus `library/` side by side in the app sandbox), forces the builtin archiver, and refuses git snapshots. Two modes:

- **Standalone**: your library lives on the phone, fully offline.
- **Remote mode**: set a server URL plus token in Settings to talk to a LAN `liber-serve` instead of the local library. See [Self-hosting](/config/self-hosting/) and [Pairing](/app/pairing/).

`liber://add?url=...` links open the add dialog with the URL prefilled. The system back button closes overlays first, then returns to the library, then exits the app. Archived copies open in the system browser from the archive tab.

Continue with [Quickstart](/start/quickstart/) for the shared search syntax and command overview.
