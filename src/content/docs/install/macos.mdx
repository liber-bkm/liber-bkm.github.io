Disk imagebinary and tar.gz are available for macos. Works on both intel as well as Apple Silicon chips 

To download the desktop app, Download and install as you'd normally instally any other desktop app

<LinkButton href="https://github.com/liber-bkm/liber/releases/latest/download/liber-desktop-darwin.dmg" icon="down-arrow">liber-darwin</LinkButton>

To install CLI version along with the desktop app, download and extract the tarball and add it to your path using the following commands:

```sh
tar xzf liber-cli-darwin.tar.gz
cd liber-*
mv liber-* ~/.local/bin
```
