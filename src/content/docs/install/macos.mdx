---
title: Install on macOS
description: Install liber on macOS
---



- On macos fzf is available via homebrew 
	```sh
	brew install fzf
	```
	and `single-file-cli `can be installed using :
    
	**for apple silicon**
	```sh
	curl -L "https://github.com/gildas-lormeau/single-file-cli/releases/latest/download/single-file-aarch64-apple-darwin" -o ~/.local/bin/single-file
	```
	**for Intel**
	```sh
		curl -L "https://github.com/gildas-lormeau/single-file-cli/releases/latest/download/single-file-x86_64-apple-darwin" -o ~/.local/bin/single-file
	```
- Download `liber-darwin-arm64` if you are using M-chips or `liber-darwin-amd64` for intel chips from [latest release](https://github.com/liber-bkm/liber/releases/latest/). Rename them to liber and place them in ~/.local/bin

You can also build liber using go 

```sh
git clone https://github.com/liber-bkm/liber.git
cd liber
go build -o liber .
mv liber ~/.local/bin/ # or /usr/local/bin
```

Run `liber config` to locate the config file and set `base_dir` as needed.
