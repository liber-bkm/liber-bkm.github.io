---
title: Install on macOS
description: Install liber on macOS
---

It is recommended to build liber from source using go. But you can also download the binary from [latest release](https://github.com/liber-bkm/liber/releases/latest) and place it in you `PATH`. Arm64 is for for M chips while intel uses amd64 binaries 

1. It is recommended to compile liber, but you can download the binary from the [latest release](https://github.com/liber-bkm/liber/releases/latest) instead.

2. Install optional dependencies for search and archiving:

```sh
brew install fzf
# single-file-cli: via Homebrew or https://github.com/gildas-lormeau/single-file-cli
# ...or monolith instead: https://github.com/y2z/monolith
```

2. Clone or download the source tarball from the [latest release](https://github.com/liber-bkm/liber/releases/latest).

3. Build with Go 1.22+ and place the binary in your `PATH`:

```sh
git clone https://github.com/liber-bkm/liber.git
cd liber
go build -o liber .
mv liber ~/.local/bin/ # or /usr/local/bin
```

Run `liber config` to locate the config file and set `base_dir` as needed.
