title: Install on Linux

All dependencies are optional but are nice to have. However fall back options are available in case they are not installed 
- [fzf](https://github.com/junegunn/fzf) for cli live search
- [single-file-cli](https://github.com/gildas-lormeau/single-file-cli)for full web archives (including javascript content)
	- alternatively instead of single-file-cli, [monolith](https://github.com/y2z/monolith) can be used as well 
- `git` for history and git based syncing

<Tabs>
<TabItem label="From source">

Requires Go 1.22 or later:

```sh
git clone https://github.com/liber-bkm/liber.git
cd liber
go build -o liber .
```

Or with the Makefile:

```sh
make && sudo make install
```

</TabItem>
<TabItem label="Arch Linux">

Install the optional dependencies:

```sh
sudo pacman -S fzf
paru -S single-file-cli # or use your own method of installing packages from aur
```

To install the binary package:

```sh
wget https://github.com/liber-bkm/liber/releases/latest/download/PKGBUILD
makepkg -si
```

To install the package from latest git branch:
```sh
https://github.com/liberbkm/liber/releases/latest/download/PKGBUILD-git
mv PKGBUILD-git PKGBUILD
makepkg -si
```

</TabItem>
<TabItem label="NixOS">

Add to your flake inputs:

```nix
inputs = {
  liber.url = "github:liber-bkm/liber";
  liber.inputs.nixpkgs.follows = "nixpkgs";
};
```

Then install with `environment.systemPackages` or home-manager `home.packages`:

```nix
{ config, pkgs, inputs, ... }: {
  home.packages = [
    inputs.liber.packages.${stdenv.hostPlatform.system}.default
  ];
}
```

Or try it without installing:

```sh
nix shell github:liber-bkm/liber # enter shell with liber installed
# OR
nix run github:liber-bkm/liber # run liber commands directly 
```

</TabItem>
<TabItem label="Generic Linux">


Download the binary from [latest releases](https://github.com/liber-bkm/liber/releases/latest) and place it in your `PATH`:

```sh
# e.g.
/usr/local/bin
# or
~/.local/bin
```

</TabItem>
