## Dependencies 

Liber has no dependencies, however it allows using third party backends for archiving webpages [single-file](https://github.com/gildas-lormeau/single-file-cli) or [monolith](https://github.com/y2z/monolith). This allows including javascript content within the archived pages, liber by default disables javascript from the archived pages. Optionally `git` is required for users who want to sync using git.

<TabItem label="Generic Linux Tarball">

The compiled binary is available for every distro. You can download and add the binaries to your path from link or simply follow the shell guide below.

<LinkButton href="https://github.com/liber-bkm/liber/releases/latest/download/liber-linux-x86_64.tar.gz" icon="down-arrow">x86_64.tar.gz</LinkButton>
<LinkButton href="https://github.com/liber-bkm/liber/releases/latest/download/liber-linux-aarch64.tar.gz" icon="down-arrow" variant="secondary">ARM64.tar.gz</LinkButton>

```sh
# Download and extract
wget https://github.com/liber-bkm/liber/releases/latest/download/liber-linux-x86_64.tar.gz
tar xzf liber-linux-x86_64.tar.gz
cd liber-*
# Move the file to PATH
mv liber* /usr/local/bin # to install them system wide or use ~/.local/bin to install them per user
```

</TabItem>

<TabItem label="Archlinux">

Archlinux PKGBUILDs are available. You can download and install them using AUR manager of your choice. 

To install compiled binaries:

```sh
wget https://github.com/liber-bkm/liber/blob/main/dist/arch/liber-bin/PKGBUILD
makepkg -si
```

Or if you want to compile package yourself:

```sh
wget https://github.com/liber-bkm/liber/blob/main/dist/arch/liber/PKGBUILD
makepkg -si
```

</TabItem>

<TabItem label="NixOS">

Liber repo provides the flake to install the package. Add the repo into your flake inputs:

```nix
inputs.liber = {
    url = "github:liber-bkm/liber";
    inputs.nixpkg.follows = "nixpkgs";
};
```

Install the package either system-wide using `environment.systemPackages` or using home-manager `home.packages`

```nix
{inputs, pkgs, ... }:
{
    environment.systemPackages = [ inputs.liber.packages.${pkgs.stdenv.hostPlatform.system}.bundle ]; # you can relapce .bundle with .default or .desktop if you want cli or desktop versions only 
}
```

You can also run the package directly without installing.

```nix
nix run github:liber-bkm/liber
```

or use developmet shell 

```nix
nix shell github:liber-bkm/liber
```

:::note
Nix compiles the binaries from source so it may take some time to install the package, currenly there's no binary cache available yet.
:::

</TabItem>
