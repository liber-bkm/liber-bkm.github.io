---
title: Install on Linux
description: Install liber on generic Linux, Arch Linux, or NixOS.
---

import { Tabs, TabItem, LinkButton } from '@astrojs/starlight/components';

Optional features need `fzf` (live search), `single-file-cli` (full-page archive), and `git` (history and sync). liber itself has no runtime dependencies.

<Tabs>
<TabItem label="Generic Linux">

Download the binary from [latest releases](https://github.com/naurias/liber/releases/latest) and place it in your `PATH`:

```sh
# e.g.
/usr/local/bin
# or
~/.local/bin
```

</TabItem>
<TabItem label="Arch Linux">

Install the optional dependencies above, then:

```sh
wget https://github.com/naurias/liber/releases/latest/download/PKGBUILD
makepkg -si
```

</TabItem>
<TabItem label="NixOS">

Add to your flake inputs:

```nix
inputs = {
  liber.url = "github:naurias/liber";
  liber.inputs.nixpkgs.follows = "nixpkgs";
};
```

Then install with `environment.systemPackages` or home-manager `home.packages`:

```nix
{ config, pkgs, inputs, ... }: {
  home.packages = [
    inputs.liber.packages.${pkgs.system}.default
  ];
}
```

Or try it without installing:

```sh
nix shell github:naurias/liber
nix run github:naurias/liber
```

:::note
Nix and Arch builds don't ship optional dependencies. Install `fzf` and `single-file-cli` separately.
:::

</TabItem>
<TabItem label="From source">

Requires Go 1.22 or later:

```sh
git clone https://github.com/naurias/liber.git
cd liber
go build -o liber .
```

Or with the Makefile:

```sh
make && sudo make install
```

</TabItem>
</Tabs>
