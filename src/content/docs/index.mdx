Rule-based automation files new bookmarks into the right folders and tags on its own, profiles keep separate collections, for example work and personal, fully independent of each other, and sync keeps every device converged without loss.

## Features

<CardGrid>
  <Card title="Capture">
    One-command add with automatic title fetch, duplicate guard, notes, file attachments, and optional archived copy. Paste several URLs at once with a per-URL report, or capture without any extension through a bookmarklet.
  </Card>
  <Card title="Organize">
    Tags and folders with merge semantics, autocomplete and suggestions in every dialog, and automation rules that stick: manual moves are never overwritten, with a learner that suggests rules from your library.
  </Card>
  <Card title="Find">
    Instant search with relevance ranking, deep full-text search across saved pages and notes with expandable match snippets, saved search presets in the sidebar, site icons, and a fuzzy terminal picker plus `Ctrl+K` palette.
  </Card>
  <Card title="Verify">
    Link checker with safe bulk actions (update moved URLs with title refetch, quarantine dead ones) and reindex repair that adopts orphans, relinks siblings, and rebuilds search without ever deleting your data.
  </Card>
  <Card title="Multiply">
    Every action on every frontend: CLI, web UI, offline desktop app, Android app, or self-hosted server with token auth and remote mode. Multi-device sync with tombstones and idempotent replay, plus one-click backup and restore.
  </Card>
</CardGrid>
