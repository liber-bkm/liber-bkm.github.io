---
title: Finding in the apps
description: Library search, detail drawer, and the command palette.
---

The Library search accepts the same `field:value` syntax as the CLI (`title:`, `url:`, `tag:`, `folder:`, `desc:`), plus a field selector restricting bare words and a Deep toggle that searches saved page content and notes with highlighted match snippets (click a snippet to expand it; Deep is slower). Saved search presets live in the sidebar with one-click apply; the save button beside the Deep toggle stores the active query under a name you choose. Sort, card and table views (table rows carry small favicons), and windowed rendering for large libraries work the same on web and desktop; the phone layout uses drawer navigation.

The detail drawer opens from any row: inline edit for every field (with tag autocomplete and folder suggestions), two-step delete, attachment upload and per-file remove, notes editor, archive viewer (inline or new tab), and open history. Full UUIDs appear in the drawer header; short ids are shown everywhere else.

The command palette (`Ctrl+K`) covers fuzzy search plus navigation and actions from the keyboard. History has its own page with open counts.

Search syntax details: [Searching](/cli/searching/). Editing from the terminal: [Editing](/cli/editing/).
