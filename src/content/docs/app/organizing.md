---
title: Organizing in the apps
description: Tags, folders, rules, and bulk actions through the UI.
---

The tags and folders pages use the same merge semantics as the CLI: renaming a tag onto an existing tag merges the two; renaming a folder moves its whole subtree; deleting a folder moves its bookmarks back to the root. The bulk bar acts on multi-select: delete (confirmed), set tags, move folder.

The rules page mirrors the CLI rule commands with learn suggestions inline: suggested host rules from your folder clusters can be created with one click, and each rule has its own apply with review. The applied-rules ledger protects manual moves everywhere, whichever frontend classified the bookmark.

CLI equivalent: [Tags and folders](/cli/tags-folders/), [Automation](/cli/automation/).
