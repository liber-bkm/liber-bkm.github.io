On first run, `liber init` walks you through setup (base dir, device id, backend, token). It refuses when already configured.

## 2. The capture loop

```sh
liber add https://example.com -t reading --folder tech
liber add <url1> <url2> -t reading   # several at once, shared flags
liber list
liber open 1
liber serve
```

Open the printed address in a browser. That is the whole loop: capture from anywhere, find instantly, open with history, and optionally serve the library to your network.

Bookmarks are addressed by short numeric id (`edit 3`) or UUID prefix, with comma lists and dash ranges (`edit 1-3,5`, at most 1000 ids per range). Ids are per-device display aliases; sync merges by UUID and never renames them.

## 3. Search syntax

Search terms accept `field:value` prefixes (`title:`, `url:`, `tag:`, `folder:`, `desc:`, with `tags:` and `description:` synonyms), combined with free words; every term must match. Quote multi-word values (`tag:"rust web"`). A bare word searches all fields; `--in` on the CLI, the `scope` API parameter, and the Library field selector restrict bare words to listed fields (names or letters `n,u,t,d,f`). Prefixes always win for their own term. The same syntax works in `list`, `open`, the `pick` and web search boxes, and desktop and mobile search.

## 4. Every command

Details live under [CLI guide](/cli/adding/) and [Reference](/reference/cli/):

```text
add <url>                      add bookmark (--title -t --folder --description --markdown --archive --attach; -i prompts for missing fields, needs a terminal)
add <url1> <url2> ...          add several at once (shared flags; single-URL flags refused)
list [query]                   search and list, newest first (--sort newest|oldest|visited|title, --in title,url,tag,folder,desc, --deep); [md]/[arch] markers
open <spec>                    open in browser, records history (falls back to search on miss)
edit <spec>                    update fields; with no flags opens the full terminal editor
pick [query]                   fuzzy picker, then open, archived copy, notes, or edit (prints the URL when piped; see [Terminal UI](/cli/terminal-ui/))
delete <spec>                  delete with confirm (--yes skips it)
attachments <spec>             list attachments with numbers
archive <spec>                 archive page (--backend builtin|browser|single-file|monolith|auto)
reindex [--prune --compact-ids]  repair library; --compact-ids closes id gaps to dense 1..N
export --site [dir] / --bookmarks <file>  static site / Netscape file
import <file>                  Netscape import (--markdown --archive), duplicates skipped, archive failures reported as warnings
backup <file>                  self-contained tarball of the library
restore <file>                 replace library from a backup (--force with confirm, --yes skips it), then reindexes
tags list|rename|delete        rename merges onto existing tags
folders list|rename|delete     rename moves subtrees, delete moves to root
auto ...                       rules: add, list, edit, apply, learn, delete
check [spec]                   link check (--workers N --stale 7d --apply; TTY apply prompts per item)
sync export|import             exchange merge bundles between devices
sync push <url> | pull <url>   push or pull bundles over HTTP (--token, --since cursor)
sync commit [--push]           git snapshot of the base dir (never inits a repo)
sync prune [--days N]          drop oplog entries older than N days (default 90)
searches ...                   saved search presets: add, list, run, delete
config get|set|list            configuration keys (see Configuration)
init                           first-run setup wizard (needs a terminal)
history                        recently opened with open counts
profile list|switch|delete     named base-dir profiles sharing one config
completion <shell>             shell completions (bash, zsh, fish, powershell, elvish)
serve                          self host API plus web UI; prints localhost and LAN URLs (--qr pairing code, mDNS on unless --no-mdns)
discover                       list liber servers on the local network (--timeout)
```
